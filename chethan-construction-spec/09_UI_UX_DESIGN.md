# 09 — UI/UX Design Specification

## Brand direction
Chethan Construction should feel:
- Trustworthy.
- Premium.
- Modern.
- Architectural.
- Professional.
- Local and approachable.

## Suggested visual language
- Neutral/earth-tone base.
- One strong accent.
- Large construction photography.
- Clean cards.
- Strong headings.
- Minimal decorative effects.

Do not lock the exact brand colors until the owner provides the logo/brand assets.

## Project card
Show:
- Cover photo.
- Project title.
- Type.
- Location.
- Status.
- View project.

## Project detail
Prioritize visual storytelling:
1. Hero/cover.
2. Project facts.
3. Description.
4. Before/During/After.
5. Gallery.
6. Video.
7. Enquiry CTA.

## Mobile UX
- Hamburger menu.
- Large tap targets.
- Horizontal filter controls where appropriate.
- Optimized gallery.
- Sticky/collapsible enquiry CTA if useful.

## Animation
Use subtle transitions:
- Fade.
- Slide.
- Scale on cards.

Respect `prefers-reduced-motion`.

## Forms
Show:
- Labels.
- Required indicators.
- Inline validation.
- Clear success state.
- Clear failure state.

## Empty states
Example:
"No projects have been published yet."

Admin:
"No enquiries yet."

## Design rule
Real project media is the visual hero of the website. Do not cover it with excessive UI.
