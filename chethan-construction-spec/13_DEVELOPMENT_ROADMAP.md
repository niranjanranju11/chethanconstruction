# 13 — Development Roadmap

## Phase 0 — Confirm business information
Collect:
- Logo.
- Company name/legal display name.
- Tagline.
- Phone/WhatsApp.
- Email.
- Address/service area.
- Services.
- Existing projects.
- Project photos/videos.
- Approved testimonials.
- Social links.

## Phase 1 — Repository and foundation
- Create GitHub repository.
- Create frontend.
- Create backend.
- Configure PostgreSQL.
- Configure Flyway.
- Configure local Docker Compose.
- Add base README.

## Phase 2 — Backend foundation
- Spring Boot configuration.
- Global exception handling.
- API response model.
- PostgreSQL entities.
- Repositories.
- Migrations.
- OpenAPI.
- Health endpoint.

## Phase 3 — Authentication
- Admin user.
- Password hashing.
- Spring Security.
- Access/refresh strategy.
- Authorization.
- Login/logout.
- Rate limiting.

## Phase 4 — Public website
Build:
- Home.
- About.
- Services.
- Projects.
- Project detail.
- Contact.

Use temporary demo content until owner content arrives.

## Phase 5 — Admin panel
Build:
- Dashboard.
- Project CRUD.
- Services CRUD.
- Testimonials CRUD.
- Company profile.

## Phase 6 — Media
- R2 integration.
- Signed upload.
- Upload progress.
- File validation.
- Media metadata.
- Gallery ordering.
- Cover image.
- Before/During/After.
- Delete/cleanup.

## Phase 7 — Enquiries
- Public form.
- Validation.
- Rate limiting.
- Admin enquiry list.
- Status.
- Notes.

## Phase 8 — Quality
- Unit tests.
- API tests.
- Frontend tests.
- Security review.
- Mobile testing.
- Accessibility.
- Performance.
- SEO.

## Phase 9 — Deployment
- PostgreSQL.
- Backend hosting.
- R2.
- Frontend hosting.
- Domain.
- HTTPS.
- Environment variables.
- Monitoring.

## Phase 10 — Owner handover
Provide:
- Admin URL.
- Admin usage guide.
- Backup explanation.
- Media upload rules.
- Recovery procedure.
- Provider account ownership information.

## Future enhancements
Only after v1 is stable:
- Multiple admin users.
- Roles.
- Gallery albums.
- Automated video transcoding.
- WhatsApp notifications.
- Email notifications.
- Analytics dashboard.
- Blog.
- Multilingual Kannada/English.
